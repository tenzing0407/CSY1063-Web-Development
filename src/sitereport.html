Site Development Report

My Learning Experience

Throughout the CSY1063 Web Development module, I gained practical experience in building a responsive portfolio website using HTML, CSS, and GitHub. At the beginning of the module, I found it quite hard to understand how HTML structure and CSS styling work together. Basic tasks such as linking CSS files correctly, organising page layouts, and ensuring consistency across multiple pages were challenging. Small mistakes, such as incorrect file paths or missing tags, often caused the website to break, which was frustrating. As I progressed through the module, I developed a stronger understanding of semantic HTML and the importance of using correct elements such as header, nav, main, and footer. I learned how to use CSS for layout and styling, particularly Flexbox and Grid, which helped me organise content more effectively. Implementing media queries allowed me to make the website responsive and adaptable to different screen sizes. Debugging also became an important part of my learning, and I gained confidence in identifying and fixing issues using browser developer tools and careful testing. In addition, using GitHub throughout the development process helped me understand version control and the importance of committing work regularly. This experience improved my ability to manage code and track changes over time. Overall, this module significantly improved my technical skills and confidence in building basic responsive websites from scratch.

Reflective Discussion

Reflecting on my experience in this module, I believe that I have developed a much clearer understanding of web development principles and best practices. This project helped me realise the importance of planning, organisation, and consistency when developing a website. By structuring my files properly and reusing components such as the navigation menu across all pages, I was able to maintain a consistent user experience. If I were to continue developing this website, I would focus on improving the visual design and adding more interactive elements using advanced CSS or JavaScript. I would also spend more time planning the layout before starting development to reduce errors during the coding process. Through this reflective process, I have recognised areas where I can improve and build upon the skills learned in this module. Overall, this module has provided me with a strong foundation in client-side web development. The knowledge and experience gained will be valuable for future projects and further studies in web development, and it has increased my confidence in explaining and demonstrating my work.
